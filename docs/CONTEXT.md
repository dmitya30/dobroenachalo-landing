## 3. Целевая аудитория

**Основная ЦА:** мамы 30–45 лет из коттеджных посёлков рядом со школой (Истра / Нахабино / Красногорск). Доход семьи выше среднего, мама либо домохозяйка, либо работает удалённо/частично. Ищет "по-московски стильное" решение для ребёнка.

**Ключевые боли/триггеры ЦА:**
- Безопасность ребёнка (закрытая территория, мало детей, охрана)
- Индивидуальный подход (ребёнок — не "номер в толпе")
- Качественное питание (нутрициолог, свежие продукты)
- Экология (живописное экологически чистое место vs городской сад)
- Преемственность (единая среда сад → школа без смены коллектива и педагогов; летом — "Доброе лето")
- "Свой круг" (камерность, дети из похожих семей)
- "Уроки в школе" (домашка делается на продлёнке — вечер свободен для семьи) — подтверждено отзывами как сильный триггер

**Дополнительная ЦА (через кружки):** мамы, которые не готовы отдать ребёнка в частный сад, но готовы водить на логопеда / шахматы / столярку / подготовку к школе / хореографию / психолога. Низкий порог входа = трипвайер для последующей конверсии в основной продукт.

**Третичная ЦА (по отзывам):** родители, чьи дети не справились в обычной школе — переводят сюда.

### Tailwind 4 — критичное правило

Имя утилиты = `<prefix>-<полное-имя-токена>`. Например, `--color-bg-soft` → `bg-bg-soft`, **не** `bg-soft`. Не сокращать (см. PROGRESS.md, "системный фикс").

### CTA-кнопка

Крупная оранжевая `#FF9664` с **тёмно-индиговым текстом** `#464682` (контраст 4.51:1, WCAG AA). Белый текст на оранжевом запрещён (2.85:1, fail).
