## 3. Целевая аудитория

**Основная ЦА:** мамы 30–45 лет из коттеджных посёлков рядом со школой (района Истра / Нахабино / Красногорск). Доход семьи выше среднего (муж зарабатывает 500к+), мама либо домохозяйка, либо работает на удалёнке/частично. Ищет "по-московски стильное" решение для ребёнка.

**Ключевые боли/триггеры ЦА:**
- Безопасность ребёнка (закрытая территория, охрана, мало детей)
- Индивидуальный подход (мой ребёнок не "номер в толпе")
- Качественное питание (нутрициолог, свежие продукты)
- Экология (сосновый лес, чистый воздух vs городской сад)
- Преемственность (не менять сад → школу → лагерь)
- "Свой круг" (камерность, дети из похожих семей)
- "Уроки в школе" (домашка делается на продлёнке — вечер свободен для семьи) — подтверждено отзывами как сильный триггер

**Дополнительная ЦА (через доп. занятия):** мамы, которые не готовы отдать ребёнка в частный сад, но готовы водить на логопеда / акробатику / подготовку к школе / шахматы / столярку. Низкий порог входа = трипвайер для последующей конверсии в основной продукт.

**Третичная ЦА (по отзывам):** родители, чьи дети не справились в обычной школе (стресс, нелюбовь к учёбе) — переводят сюда. Возможно вынести в отдельный кейс/блок.

- Индиго/тёмно-синий `#3D3F7A` — основной, текст, заливки

### CTA-кнопка
"Большая красная кнопка" — нарицательное от заказчика. По факту — **только брендовые цвета**: крупная оранжевая (`#F5A35B`) на тёмно-синем фоне, либо тёмно-синяя на светлом — выбор по контексту секции. Высокий контраст, "рука сама нажимает". Никакого внебрендового красного.

### Тон
"По-московски стильно, модно, молодёжно" (формулировка заказчика). Расшифровка: премиальная типографика, много воздуха, минимум декоративных элементов, фокус на типографике и фото. Без перегруза, без "сладких" иллюстраций мультяшных детей, без избыточных закруглений и неонов. Премиум — это сдержанность.

### Что точно НЕ делаем
- Не дублируем стиль текущего сайта (его сам заказчик назвал "кашей без продающего фактора")
- Не копируем "Академическую гимназию" (она про корпоративный масштаб, у нас семейный)

## 10. Структура лендинга (скелет v2, обновлён)

1. **Шапка** — лого слева, телефон+CTA "Записаться на экскурсию" справа, иконки TG/MAX/VK. Sticky

## 11. Ключевые смыслы и УТП

### Главные сообщения для лендинга (приоритезировано)

3. **Камерность** — до 10 детей в классе, 8–12 в саду
4. **Закрытая территория в сосновом лесу** — критично для мамы из коттеджа; в 380 м от станции

6. **Альтики** — внутренняя школьная "валюта" за достижения, обмен на призы в школьном магазинчике. Уникальная фишка, которой нет у конкурентов
7. **Шахматы как часть системы** (а не доп. кружок) — с детского сада, дисциплина мышления
8. **Зимой все дети катаются на лыжах** — сильный сезонный/визуальный аргумент
9. **Продлёнка с домашкой** — вечер свободен для семьи (подтверждено отзывами как боль ЦА)
10. **Питание от нутрициолога** — ежедневная готовка, свежие продукты
11. **Английский с младших групп** — не "с 1 класса", а с дошкольников
12. **Школа, которую родители сделали для своих детей** — основатели водят сюда своих троих детей. Аутентичность

## 12. Принятые решения (с обоснованием)

| Решение | Обоснование |
|---|---|
| Astro + Tailwind + GH Pages | Стек заказчика "не Тильда, бесплатный хостинг". Astro даёт идеальный Lighthouse и компонентность, GH Pages — бесплатный CDN+HTTPS |
| Без формы заявки | Заказчик не хочет возиться с 152-ФЗ. CTA = звонок (`tel:`). Для нашей ЦА это даже естественнее |
| Цены показываем явно | Прозрачность = доверие в премиум-сегменте. Конкуренты прячут, мы выделимся |
| 4 карточки команды + expandable | Меньше шума на первой загрузке, нет дублирования контента, сохраняем формат одностраничника |
| Лицензию НЕ светим | Заказчик: документ есть, но "не для показа". Аттестат — упоминаем одной строкой через школу-партнёра |
| Email НЕ публикуем | Решение заказчика |
| "Сколько лет / сколько детей" НЕ публикуем | Решение заказчика. Жаль (сильные пруфы), но не настаиваем |
| Микро-CTA "пробный день 2900" сохраняем | Низкий порог входа, готовый трипвайер |
| Главный CTA "Записаться на экскурсию" (бесплатно) | Заказчик одобрил |
| MAX упоминаем (иконкой рядом с кнопкой) | Часть мам предпочитает писать, а не звонить. Тот же номер |
| WhatsApp НЕ упоминаем | Заказчик принципиально против |
| Отзывы — берём реальные (вариант B) | Найдено 29 публичных отзывов с рейтингом 4,7 — используем их. Имена сохраняем, "Альт*" заменяем на обезличенное |
| CTA только в брендовых цветах | "Красная кнопка" = нарицательное. Используем оранжевый из палитры — высокий контраст с индиго-фоном |
| Полный календарь 12 смен на лендинге | Найден в ТГ, важный продающий элемент: видна вся программа лета |
| 5 карточек доп. занятий (а не 3) | После анализа листовок добавились столярка и шахматы. Шахматы с бесплатным пробным — сильный лид-магнит |
