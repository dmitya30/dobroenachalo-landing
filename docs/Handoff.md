## Что делаем

## Стек (зафиксирован, не меняем без причины)

Astro 5.x (static) · Tailwind 4.x · TypeScript strict · Node 20 · pnpm · GitHub Pages + CNAME · Yandex.Metrica · без серверной логики, без CMS, без форм (только `tel:` и мессенджеры).

## Входные документы (приложены отдельно)

1. **CONTEXT.md v1.1** - единый источник правды по проекту (бизнес, ЦА, цены, контакты, решения).
2. **Texts v0.1** - готовые тексты для всех 16 секций с пометками `[ссылка]`, `[фото]`, `[согласовать]`.
3. **Astro Project Blueprint v0.1** - структура каталогов, карта компонентов, контент-модель, дизайн-токены, SEO, CI/CD, бюджеты производительности.
4. **raw-assets/** - листовки (5 шт.), отзывы (11 шт.), фото из Telegram/Я.Карт/сайта.

**Что НЕ из пайплайна:**
- Секция 3 (Offer Cards, 4 карточки) - фото не отбирались. Используем **иконки в фирменных цветах с текущего сайта** `dobroenachalo.ru`. Поскрапить в начале фронтенд-диалога, сохранить как SVG в `src/icons/offer/`. Если потребуется - заменить на фото из shortlist-backup позже.

**Юридические флаги:**
- 1 фото в `selected/` помечено `full_face_consent_required` в metadata.json - перед публикацией клиент подтверждает согласие родителей. Если согласия нет - берём резервное фото из shortlist-backup той же секции.
- 13 портретов команды взяты с действующего сайта без обработки (заказчик уже их публикует - согласия по факту есть).

**Передача в фронтенд:**
1. Скопировать содержимое `~/dobroenachalo-media/dist/src/assets/` в `src/assets/` Astro-проекта (12 подпапок).
2. При генерации `alt`-атрибутов использовать поле `description` из `metadata.json`.
3. Передать клиенту список фото с `full_face_consent_required` перед первым публичным деплоем.

**Резервы и регенерация:**
- Папка shortlist-backup в `~/dobroenachalo-media/shortlist/` содержит 90 кандидатов сверх отобранных - на случай замен.
- Пайплайн идемпотентный: при поступлении свежих фото от клиента - складываем в `raw-assets/fresh-from-client/`, перезапускаем скрипты 01→06, время - 30-60 минут, стоимость - пропорционально объёму.
