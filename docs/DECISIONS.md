- **Astro 6.3.3** + Tailwind 4 + TypeScript strict + pnpm 11 (Node 22)
- Деплой: GitHub Actions → GitHub Pages (стейджинг)
- Стейджинг: `https://dmitya30.github.io/dobroenachalo-landing/`, продакшн (планируется): `dobroenachalo.ru`

### Tailwind 4 — критичные правила
- Имя утилиты = `<prefix>-<полное-имя-токена>`. `--color-bg-soft` → `bg-bg-soft`, **не** `bg-soft`
- Это уже создавало регрессии (см. PROGRESS.md, «системный фикс»)
