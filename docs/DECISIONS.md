## 2026-05-17 — Рефакторинг Header / Hero / Footer по DESIGN.md

### Header
- **CTA-кнопка**: «Позвонить» + иконка телефона (inline lucide-style SVG), не текст номера. Номер показывается в Hero и Contacts.
- **Размер кнопки в Header**: `size="md"` на десктопе, `size="sm"` в мобильном меню. Исключение из общего правила DESIGN §5 («главный CTA = `lg`»), потому что Header — утилитарный контекст. Главный CTA `lg` — только в Hero и в детальных секциях.
- **Подпись «Написать:» убрана** перед иконками соцсетей — иконки самодостаточны.
- **Лого-ссылка использует `import.meta.env.BASE_URL`** — необходимо для GitHub Pages (`/dobroenachalo-landing/`).

### Hero
- **H1 = «Частная школа-сад в сосновом лесу под Москвой»** (texts.md вариант A — продающий, «обещание-first»). Бренд-имя «Доброе Начало» появляется в шапке и в Footer, в Hero не дублируется.
- **Lead под H1**: одна короткая фраза с возрастом и единым путём «сад → школа → лагерь».
- **4 чипа** под lead: `RatingBadge` (4,7 ★ Яндекс.Карты) + 3 info-чипа (классы до 10, сосновый бор, МЦД Нахабино Ясное). Стиль всех четырёх — единый (`bg-white/15 backdrop-blur-sm`).
- **Градиент overlay адаптивный**: на мобиле `bg-gradient-to-b` (текст внизу читаем поверх затемнения), на десктопе `bg-gradient-to-r` (классический сайд-фейд).
- **CTA-блок**: на мобиле — column (большая кнопка сверху, телефон+мессенджеры снизу), на планшете+ — row.

### Footer
- **Лого: `variant="mark"` (герб)** до получения белой версии compact. Высота 64px, чтобы визуально соответствовать compact 48px.
- **4 колонки на десктопе**: лого+описание / навигация / контакты / соцсети. На планшете 2×2, на мобиле — стек.
- **Заголовки колонок — Manrope (`font-sans`)**, не Cormorant. Исключение из DESIGN §3: serif плохо читается в плотном мелком тексте футера.
- **`mt-16` убран** — вертикальный ритм задаёт последняя секция страницы, не футер.

### RatingBadge — расширение
- Добавлен prop `variant: 'default' | 'on-dark'`. `on-dark` использует `bg-white/15` + белый текст для тёмных фонов (Hero, потенциально Contacts на индиго).

### Иконки в Header / Hero / RatingBadge
- **Inline lucide-style SVG** до установки `astro-icon`. Когда библиотека будет установлена — заменим на `<Icon name="lucide:..." />` одной правкой.


## 2026-05-17 — Подключение astro-icon + Lucide

### Установка
- Установлены `astro-icon@1.1.5` + `@iconify-json/lucide@1.2.107`.
- Интеграция `icon()` подключена в `astro.config.mjs`.
- Совместимость с Astro 6.3.3 проверена: проблема `astro-icon` с Astro 6 относится только к Cloudflare adapter v13 + workerd; у нас static output на GitHub Pages — нерелевантно.

### Применение Lucide
- **Header**: `lucide:phone` (кнопка «Позвонить»), `lucide:menu` (бургер мобильного меню).
- **Hero chips**: `lucide:users` (классы до 10), `lucide:trees` (сосновый бор), `lucide:train-front` (МЦД).
  - `train-front` выбран как привычный визуальный якорь для упоминания станции в недвижимости. Хотя ЦА возит детей на личном авто, иконка поезда понятнее всего считывается с «380 м от МЦД».
- **RatingBadge — звезда**: **оставлен кастомный inline SVG** с `fill="currentColor"`. Lucide-звезда по умолчанию контурная (`fill="none"`), и попытка переопределить через `style="fill: currentColor; stroke: none;"` не дала визуального эффекта (вероятно, специфичность атрибута SVG vs inline style, либо `astro-icon` инлайнит SVG с приоритетным атрибутом). Не стали копать — кастомный SVG надёжно даёт залитую оранжевую звезду.

### Правило: когда Lucide, когда кастомный SVG
- **Lucide через `<Icon>`** — для контурных утилитарных иконок (UI-элементы, чипы, состояния).
- **Кастомный inline SVG** — для:
  - залитых форм (рейтинг-звезда),
  - брендовых иконок соцсетей (TG, Макс, VK — их нет в Lucide или нужны строго брендовые цвета).
- Если в будущем понадобится залитая Lucide-иконка — сначала проверить, не проще ли скачать SVG и вставить inline, чем бороться с переопределением `fill`.
