## ПАЛИТРА v2.0 (новая, под премиальный вид)

**Контекст:** заказчица в претензиях назвала текущую палитру «простоватой, неприятной глазу», голубой `#A0EBFF` — «неоновый, раздражающий». Хочет «премиальный лендинг, по-московски, эксклюзив». Проблема была не в цветах из лого, а в их применении: фирменные `#A0EBFF` и `#FFDCB4` работают как акценты на 5-10% площади, но не как фоны на 30-50%.

**Решение:** уход в монохромные нейтрали с тёплым подтоном. Цвет приходит через акценты (CTA, индиго, фото), а не через фоновые заливки. Стандартный приём премиальных лендингов частных школ.

### Новые токены (заменяют текущие в `global.css` `@theme`)

```css
@theme {
  /* Фоны — слоновая кость и тёплые нейтрали */
  --color-bg:        #FAF8F4;  /* основной фон — НЕ белый, слоновая кость */
  --color-bg-soft:   #F1ECE3;  /* дымчатый бежевый, на тон темнее */
  --color-bg-warm:   #FFFFFF;  /* чистый белый — теперь АКЦЕНТНЫЙ фон */
  --color-bg-mute:   #E8E3D9;  /* для разделителей и тонких подложек */
  --color-indigo-soft: #DDE0EE; /* НОВЫЙ — разбавленный индиго для секций с акцентом */

  /* Акценты — без изменений */
  --color-cta:           #FF9664;  /* оранжевый, остаётся */
  --color-cta-dark:      #E07A4A;  /* оранжевый-тёмный */
  --color-indigo:        #464682;  /* индиго основной */
  --color-indigo-dark:   #33335E;  /* индиго тёмный (footer, hero) */
  --color-indigo-muted:  #6E78B4;  /* индиго мягкий */

  /* Текст */
  --color-ink:        #2B2A29;  /* чернила, основной текст */
  --color-text-muted: #6B6B6B;  /* приглушённый текст */
}
```

### Что меняется визуально

1. **Основной фон сайта — слоновая кость `#FAF8F4`**, а не белый. Это **главное** изменение, дающее премиальность с первого взгляда. Эффект «качественной бумаги».
2. **Белый `#FFFFFF` становится акцентным** — карточки на тёплом фоне «всплывают», читаются как премиум-блоки.
3. **Голубой `#A0EBFF` исчезает из фонов** полностью. Сохраняется только как **акцентный цвет** в иконках OfferCards (где уже используется в SVG).
4. **Кремовый `#FFDCB4` исчезает из фонов** — но логика «тёплых» секций сохраняется через `bg-soft` (дымчатый бежевый).
5. **Новый `indigo-soft #DDE0EE`** — для секций, которым нужен ненавязчивый цветовой акцент (например, Reviews или одна из продуктовых).
