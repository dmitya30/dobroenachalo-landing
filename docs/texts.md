## 📌 Регламент работы с чанками

- **Правки текстов** вносятся в соответствующий чанк (`texts-N-M.md`), `texts-all.md` НЕ синхронизируется (он бэкап).
- **Журнал решений** — записывается в `texts-journal-end.md` и/или `DECISIONS.md` (приоритет — DECISIONS.md).
- **При создании новой секции** — добавьте её в этот индекс (`texts.md`) и в соответствующий чанк.
- **Поиск:** для поиска по всему контенту разом — используйте `texts-all.md` (актуален на 2026-05-20, до волн рефакторинга); для актуального текста — соответствующий чанк.
