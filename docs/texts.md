**Что делать, если ребёнок заболел во время смены?**
Если ребёнок почувствовал себя нехорошо — он остаётся дома до полного выздоровления. После возвращения пропущенные дни спокойно отрабатываются в удобное для вас время — в рамках текущей смены или с переносом на следующие недели. Главное — чтобы ребёнок вернулся бодрым и с улыбкой.

Наши вожатые умеют мягко вовлечь даже самых сдержанных. Если ребёнок пока хочет понаблюдать со стороны или отдохнуть — мы уважаем его границы. Главное — чтобы в смене было комфортно.

**Что если у ребёнка день рождения во время смены?**
Мы с радостью поможем создать праздничную атмосферу: поздравим именинника вместе с отрядом, выделим время для поздравлений и поможем с организацией момента. Угощения и детали праздника родители готовят заранее по договорённости с вожатыми.

## ПАЛИТРА v2.0 (новая, под премиальный вид)

**Контекст:** заказчица в претензиях назвала текущую палитру «простоватой, неприятной глазу», голубой `#A0EBFF` — «неоновый, раздражающий». Хочет «премиальный лендинг, по-московски, эксклюзив». Проблема была не в цветах из лого, а в их применении: фирменные `#A0EBFF` и `#FFDCB4` работают как акценты на 5-10% площади, но не как фоны на 30-50%.

**Решение:** уход в монохромные нейтрали с тёплым подтоном. Цвет приходит через акценты (CTA, индиго, фото), а не через фоновые заливки. Стандартный приём премиальных лендингов частных школ.

### Новые токены (заменяют текущие в `global.css` `@theme`)

```css
@theme {
  /* Фоны — слоновая кость и тёплые нейтрали */
  --color-bg:        #FAF8F4;  /* основной фон — НЕ белый, слоновая кость */
  --color-bg-soft:   #F1ECE3;  /* дымчатый бежевый, на тон темнее */
  --color-bg-warm:   #FFFFFF;  /* чистый белый — теперь АКЦЕНТНЫЙ фон */
  --color-bg-mute:   #E8E3D9;  /* для разделителей и тонких подложек */
  --color-indigo-soft: #DDE0EE; /* НОВЫЙ — разбавленный индиго для секций с акцентом */

  /* Акценты — без изменений */
  --color-cta:           #FF9664;  /* оранжевый, остаётся */
  --color-cta-dark:      #E07A4A;  /* оранжевый-тёмный */
  --color-indigo:        #464682;  /* индиго основной */
  --color-indigo-dark:   #33335E;  /* индиго тёмный (footer, hero) */
  --color-indigo-muted:  #6E78B4;  /* индиго мягкий */

  /* Текст */
  --color-ink:        #2B2A29;  /* чернила, основной текст */
  --color-text-muted: #6B6B6B;  /* приглушённый текст */
}
```

### Что меняется визуально

1. **Основной фон сайта — слоновая кость `#FAF8F4`**, а не белый. Это **главное** изменение, дающее премиальность с первого взгляда. Эффект «качественной бумаги».
2. **Белый `#FFFFFF` становится акцентным** — карточки на тёплом фоне «всплывают», читаются как премиум-блоки.
3. **Голубой `#A0EBFF` исчезает из фонов** полностью. Сохраняется только как **акцентный цвет** в иконках OfferCards (где уже используется в SVG).
4. **Кремовый `#FFDCB4` исчезает из фонов** — но логика «тёплых» секций сохраняется через `bg-soft` (дымчатый бежевый).
5. **Новый `indigo-soft #DDE0EE`** — для секций, которым нужен ненавязчивый цветовой акцент (например, Reviews или одна из продуктовых).

### Технические пометки по миграции

1. **Правка одного файла:** `src/styles/global.css` в блоке `@theme` — заменить 4 переменные фонов + добавить `--color-indigo-soft`.
2. **Затронутые секции:** 11 из 16 (см. таблицу). По 1-2 утилиты в каждой — около 15 точечных правок в `.astro`-файлах.
3. **Tailwind 4 naming:** имя утилиты = `bg-<полное-имя-токена>`. Например, `--color-indigo-soft` → `bg-indigo-soft`, **не** `bg-soft`. Не повторить старую ошибку (см. PROGRESS.md, «системный фикс»).
4. **Кнопки и иконки:** не трогаем. CTA остаётся оранжевый на индиго-тексте (контраст 4.51:1, AA).
5. **OfferCards SVG-иконки:** оставляем как есть — `#A0EBFF` и `#FFDCB4` в иконках работают как акценты, не как фон.
6. **Lighthouse контраст:** новые комбинации текст-фон нужно перепроверить:
   - Чернила `#2B2A29` на слоновой `#FAF8F4` → контраст ~15:1, AAA ✓
   - Индиго `#464682` на бежевой `#F1ECE3` → ~7:1, AAA ✓
   - Чернила на `indigo-soft #DDE0EE` → ~13:1, AAA ✓
   Все комбинации безопасны.

### Альтернативные варианты (не выбраны, для справки)

- **Вариант 1 — «Безопасный»** (`#EAF7FB` / `#FBF1E6` / `#F6F4F0`): осветление текущих фирменных цветов в 3-4 раза. Сохраняет узнаваемость лого, но премиальности не даёт.
- **Вариант 3 — «Природный»** (off-white + шалфей `#8FA888` + охра): уход в природную палитру, эстетика осознанного образования. Самый смелый, но рискованный — заказчица может не принять отход от голубо-оранжевой палитры лого.

Выбран **Вариант 2 — «Премиальный»** как баланс премиальности и риска.

- **Применять ДО показа заказчице сайта с новыми текстами**, не после

### Технические решения

- **Multi-channel CTA везде:** большая оранжевая кнопка `tel:` + строка «или напишите» + иконки TG / Макс / VK
- **`SocialIcons mode="contacts"` + VK** — расширить компонент (раньше contacts = только TG + Макс, channels = + VK)
- **Tailwind 4 naming:** `bg-<полное-имя-токена>`, не сокращать
- **Каждая секция — отдельный коммит** `content(<section>): ...`
- **Палитра — отдельный коммит** `style(palette): ...`
